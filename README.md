# Newspaper Homepage Skill

A Codex skill for turning supplied links, accessible reading material, or source notes into a sourced newspaper-style homepage or digest.

## Skill

The installable skill is in [`newspaper-homepage/`](newspaper-homepage/). Copy that folder into your Codex skills directory to use it. It covers source-grounded editorial content and the broadsheet reference layout: oversized masthead, edition strip, three story columns, red section labels, and the `YOUR DAY` / `THE ALMANAC` right rail.

## Example

[`examples/shreya-shankar-newspaper.html`](examples/shreya-shankar-newspaper.html) is a standalone responsive example built from Shreya Shankar's public profile. It demonstrates the layout with source-linked content.

## Source reference

The newspaper visual reference is [ThariqS/ai-newtab](https://github.com/ThariqS/ai-newtab), whose README describes a configurable newspaper-style new-tab page.
