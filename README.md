# Newspaper Homepage Skill

A Codex skill for turning supplied links, accessible reading material, or source notes into a verified newspaper-style front page.

## Skill

The installable skill is in [newspaper-homepage/](newspaper-homepage/). Copy that folder into your Codex skills directory. It follows the compact newspaper layout: oversized masthead, three story columns, red section labels, and the **YOUR DAY** / **THE ALMANAC** right rail.

## Example

[ricky-macharm-resume-newspaper.html](examples/ricky-macharm-resume-newspaper.html) is a responsive resume edition based on Ricky Macharm’s public 2025 CV and current SisengAI profile. It omits personal contact and address details. GitHub shows HTML files as source code; download the example and open it in a browser to view the layout.

## Source reference

The newspaper visual reference is [ThariqS/ai-newtab](https://github.com/ThariqS/ai-newtab), whose README describes a configurable newspaper-style new-tab page.
